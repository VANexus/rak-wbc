# tests

## 分层

| 层 | 位置 | 内容 |
|---|---|---|
| 单元测试 | 各包 `test/` | 数学、坐标变换、消息序列化、QP 可行性 |
| 集成测试 | `tests/integration/` | 状态估计 + 控制 + 假硬件；录制回放 |
| 场地回归 | `tests/field/` | 真赛道逐项：平地/斜坡/碎石/台阶/跨栏/起身/负重 |
| 故障注入 | `tests/fault/` | 单传感器失效、通信中断、QP 不可行、低电量 |

## 通过判据

- 单元/集成：`colcon test` 全绿。
- 场地：每项 ≥9/10 成功；起身 ≤3 s；全程零干预。
- 故障注入：每种故障都能进入降级状态并上报 `FAULT`，不摔。

## 比赛前必跑

1. 全流程 ≥3 轮，计时。
2. 跌倒自恢复：平/斜/碎石各 10 次。
3. 边界：1.2 m 窄道不越界。
4. 急停：物理 + 无线各 3 次，卸力不甩。
5. 日志：断电后文件可读。
