## 阶段 2 · 基础设施与仿真（第 3–8 周，与阶段 1 并行）

- [ ] 实现**遥测链路**（位置/状态上行，无图像）；对接赛事裁判系统协议（待组委会答复）

- [ ] **按实测尺寸**建赛道数字孪生：碎石(10–40mm)/斜坡(10/12/15°)/台阶(3/4/5级)/跨障栏(60/80/100mm)/颠簸路面/窄道(1.2m)/弯道

**验收**：仿真中机器人能走 1.5 m/s、能过全部障碍；真机可上电自检并上报状态码。

## 阶段 3 · 下肢运动控制（第 6–16 周）← 工程重心

**交付物：六类步态 + 跌倒恢复**

- [ ] L1 状态估计：浮动基座 EKF + 接触/打滑检测
- [ ] L1 地形高度图（2.5D elevation map）+ 可通行性代价
- [ ] L2 MPC（质心 + ZMP）基线
- [ ] L2 WBC（QP：质心/姿态/摆动足/力分配/限位/限幅）
- [ ] 步态 1 平地快走 → **≥1.0 m/s 稳定**
- [ ] 步态 2 平地慢走 → **1.2 m 窄道不越界**
- [ ] 步态 3 碎石崎岖（粒径实测范围内）→ 打滑 ≤2 步恢复
- [ ] 步态 4 跨障（60/80/100 mm）→ 不碰倒障碍（不"破坏场地"）
- [ ] 步态 5 上下坡（10/12/15°）→ **下坡不前倾失稳**
- [ ] 步态 6 台阶（3/4/5 级）
- [ ] **跌倒恢复 FSM（趴/仰/侧翻）→ 平/斜/碎石路面各 10 次，成功 ≥9 次，时延 ≤3 s**
- [ ] 打滑/碎石移位/障碍微调的自主重规划（**并让过程可见**）
- [ ] 急停合规序列（缓慢卸力 → 低姿 → 断电）
- [ ] RL 策略训练（域随机化）+ 导出 TensorRT
- [ ] 双路线切换：学习策略 ↔ 模型基保守策略（**自主切换，不等人**）

**验收**：六类步态逐项通过；跌倒恢复 ≤3 s 达标；仿真→真机性能衰减可接受（≥70%）。

- [ ] 任务 2「雷区侦察」：颜色序列解析 + 视觉伺服拔线 + **顺序容错**
- [ ] 任务 3「收纳」：清单顺序解析 + 分类 + 有序放置
- [ ] **任务 3 掉落检测 → 自主拾取重试**（7 分保险，投入产出比最高）
- [ ] 任务 5「丛林投物」：抓取 + 投掷策略（先保证动作成立）
- [ ] 任务 4「伤员转运」：抱姿 + 全身协调负重行走

## 附 B · 比赛日流程 Runbook

```
T-30 min  到达、检录；设备安全检查；确认赛道实测尺寸与训练差异
T-20 min  电池就位；开机自检；传感器功能验证；状态码上屏确认
T-15 min  急停双通道测试（物理 + 无线，由质检裁判见证）
T-10 min  跌倒自恢复演示录像（这是交付材料 2，也顺便热机）
T-5  min  队伍分工确认；操作员只持急停；地面站就位
T-2  min  按 2 分钟预案：赛道外侧最终自检（不指望调参/建图）
T-0       裁判发令 → 上电/站起/进入任务状态机 → 人员撤离
比赛中    操作员：手离所有输入，只监控状态码
          盯守员：记录实际时间戳、任务档位判定、裁判口头提示
          队长：只在不服判定时当场礼貌询问（为 30 分钟窗口留证）
结束      队长签字确认成绩前，先核对：任务档位/摔倒次数/停顿次数/干预次数
          有异议 → 30 分钟内提交**书面**申诉（用模板 + 附日志证据）
赛后      导出完整日志（7.2 要求提交）；备份两份
```

## 附 C · 常见失分自查（赛前逐条打勾）

- [ ] 出现任何一次人工干预？（每次 −2，且任务降档，且可能降自主等级）
- [ ] 有任何一次"摔倒后无法自恢复/需外力"？（稳定性 6 分归零）
- [ ] 摔倒次数 >2？（第 3 次起稳定性 0 分）
- [ ] 有超过 5 秒的非必要停顿？（流畅度 −1/次）
- [ ] 有一次出界？（−2/次；且要自主退回标记点）
- [ ] 撞飞过任何障碍构件？（−3/次）
- [ ] 有"明显颠簸但仍前行"？（姿态控制 0 分）
- [ ] 15 分钟后是否出现了"停止尝试"？（→ 5.7 无效成绩，0 分）
- [ ] 状态码/轨迹上报是否全程稳定？（检查项 + 影响裁判判断）
- [ ] 日志是否掉电不丢？（7.2 交付义务）
- [ ] 身高申报与实测误差是否 ≤±8%？
