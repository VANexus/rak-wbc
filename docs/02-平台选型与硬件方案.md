# 02 · 平台选型与硬件方案（人形机器人越野赛 · 全自主组）

> 目标：在 **身高 45–170 cm、单腿 ≥4 DOF、续航 ≥25 min、全机载算力** 的约束下，
> 选出**能做出任务 1–5**的平台，并给出传感器/算力/电气/预算的完整方案。
>
> ⚠️ 下文平台参数来自公开资料（2026 年 7 月前后），**采购前必须向厂商逐项确认**，
> 特别是：足底力传感器、单臂/双臂载重、臂端接口类型、SDK 开放度、电池是否可快拆。

---

## 一、先定"要不要自研"

| 方案 | 内容 | 周期 | 预算 | 建议 |
|---|---|---|---|---|
| **Tier A** 采购成熟平台 + 自研软件 | 买整机，全部力气投在感知–规划–控制 | 6–8 月 | **25–60 万** | ✅ **强烈推荐** |
| **Tier B** 采购平台 + 改造 | 换/加算力、加上肢换灵巧手、加传感器 | 8–12 月 | 60–120 万 | ⚠️ 仅在平台某项硬伤时 |
| **Tier C** 全自研本体 | 自研关节模组、结构、控制器 | 3 年+ | 200 万+ | ❌ 2–4 人团队做不到 |

**为什么强烈推荐 Tier A：**

1. 本赛事的难点**不在造本体**，而在"感知–规划–控制"软件（自主技术分 20 分全在这里）。
2. 双足运动控制的 sim2real 本身就是顶级实验室的专长，从零自研等于放弃比赛。
3. 平台厂商已把关节驱动器、WBC 基线、ROS 2 接口做完了。**站在平台上，你的 6 个月可以全部用于得分点。**
4. 赛事 1.1 明确"一体化独立系统"，自研结构很难在 6 个月内达到"抗摔 + IP 级缓冲 + 急停 + EMC"的可靠度。

> **结论：不要造机器人，要造"会干活的机器人"。**

### 2.1 Unitree G1 EDU — 详细评估

**优点**
- 身高 127–132 cm，**身高余量最大**（离 170 cm 上限远，离 45 cm 下限也远）→ ±8% 实测误差无风险。
- **单腿 6 DOF**，远超 ≥4 的要求 → 足端姿态可控，碎石/斜坡适应性好。
- 单臂 5 DOF（EDU 可达 7），膝扭矩 90 N·m / EDU 120 N·m，**已标配 3D LiDAR（Livox Mid-360）+ 深度相机（RealSense D435i）** → 2.1 的"标配深度相机 + 可选 LiDAR"直接满足，无需加装。
- 生态最大、开源社区资料最多、二手/备件好找。
- 平地速度可达 2+ m/s → 时间分的物理基础完全够。

**风险**
- **臂载重只有 2–3 kg** → 任务 4（伤员转运）高度依赖假人质量。若假人 >5 kg，G1 基本无解。
- **SDK/ROS 2 访问需要 EDU 版**，基础版做不了自主开发 → **必须买 EDU，别贪便宜买 Basic。**
- 官方"1–2 h 续航"是轻载数据，带操作+全感知后可能只剩 30–45 min，逼近 25 min 硬线。
- 35 kg（无上肢）/ 47 kg（含灵巧手）→ **30 秒就位**的搬运需要 2–3 人 + 定制运输台车。

### 2.2 Booster T1 — 详细评估

**优点**
- **AGX Orin 200 TOPS**，是候选里机载算力最高的 → 留给 VLA 推理的余量最大（这是全自主组的命门）。
- **"抗摔 + 可自主起身"是它的产品卖点**，与 5.3 稳定性 6 分 + 5.2 任务 1 直接对齐 → **平台原生属性就打在高权重得分点上**。
- **RoboCup 2025 AdultSize 冠军**血统 → 竞赛型平台，ROS 2 全开放、有仿真环境、有 50+ 高校使用案例。
- 支持下肢 23 DOF / 夹爪 31 DOF / 灵巧手 41 DOF 三种配置 → **可以按任务清单精确定配**。
- 118 cm、30 kg（部分资料 18 kg）→ 比 G1 更好搬运。
- 单臂 4 DOF 可扩展。

**风险**
- 部分资料标称续航 1.5 h，实际带负载需实测。
- 单臂 4 DOF 是候选里最低的（刚好卡 ≥4 单腿要求是另一回事，臂 DOF 未明文要求）→ **精细操作（拔线、分类抓取）灵活性弱于 G1 EDU**。
- 臂载重标称 2–5 kg（口径不一）→ 同样受假人质量制约。

### 2.3 众擎 PM01 — 详细评估

**优点**
- **电池智能快拆 + 10000 mAh + 充电约 2 h** → 与 1.1"允许在赛场指定补给站更换电池"完美契合，是**唯一把换电当设计目标**的候选。
- 双目相机 ×2（头部/腰部）+ 3D LiDAR → 感知配置最好。
- 腰部 >300° 旋转、髋关节活动范围大 → 姿态调整能力强（对应 5.4"自主完成姿态调整" +2 分）。
- 单臂 5 DOF、髋/膝力矩声称峰值扭矩密度 130 N·m/kg 级。
- 提供底层接口 + 训练部署代码。

**风险**
- **~44.5 kg 机身**，是候选里最重的 → 30 秒就位、赛前搬运是真实负担。
- Orin NX 16G（约 100 TOPS）→ 算力不如 T1。
- 公开的自主导航/操作软件资料少于 G1/T1 → 学习成本高。
- 载重参数未公开 → 必须问。

### 2.4 选型裁决建议

| 若你的优先级是… | 选 |
|---|---|
| 算力最大、抗摔最好、有比赛血统 | **Booster T1（Dexterous Hands 版）** |
| 生态最成熟、备件最好找、身高余量最大、关节最灵活 | **Unitree G1 EDU** |
| 换电是刚需、感知配置要最好、可接受高学习成本 | 众擎 PM01 |

> **我的推荐：Booster T1 与 G1 EDU 二选一，优先 T1。** 理由是三条硬对齐：
> ① 200 TOPS 算力（全自主组的算力命门）；
> ② 抗摔 + 自主起身是原生卖点（正好是 5.3 的 6 分 + 任务 1 + 避免干预三重叠加）；
> ③ 41 DOF 灵巧手配置可直接支撑任务 2/3/5。
>
> **但先看问题清单第 1 条（假人质量）、第 2 条（急救物品重量）的回答再定。**
> 如果假人 >8 kg，**两个平台都无解**，必须转向"拖拽式转运"的降级设计 —— 那会反过来影响选型（要选腿力大、能深蹲的）。

## 四、算力方案（全自主组的命门）

### 4.1 硬约束回顾

- 2.1.5 **禁止场外实时传回图像、下发运动指令** → **不能靠地面服务器跑大模型**。
- 1.1 禁止拖曳线缆 → 不能有线供电的"外挂算力"。
- 一切推理都在机上。

### 4.2 分层算力分配

| 层 | 频率 | 算力需求 | 载体 |
|---|---|---|---|
| 关节级伺服 | 500–1000 Hz | 极低 | **关节驱动器 / 独立 MCU**（不要放 GPU） |
| 全身控制 WBC/MPC | 200–500 Hz | 低 | 实时 CPU 核（独占，绑核） |
| 状态估计（IMU+腿运动学+接触） | 200–500 Hz | 低 | 实时 CPU 核 |
| 地形高度图 / 代价地图 | 10–30 Hz | 中 | GPU（CUDA） |
| 局部规划 / 落脚点规划 | 10–50 Hz | 中 | CPU |
| 目标检测/分割/6D 位姿 | 10–30 Hz | **高** | GPU |
| **操作策略（VLA / 模仿学习）** | **5–30 Hz** | **最高** | GPU（独占显存） |
| 全局规划 + 任务状态机 | 1–5 Hz | 低 | CPU |

> **关键设计原则：把不同频率的东西彻底解耦。** 绝对不能让 30 Hz 的 VLA 推理阻塞 500 Hz 的关节伺服。
> 做法：实时核跑控制（PREEMPT_RT + CPU 隔离），GPU 跑感知/策略，中间用**无锁队列**交换。

### 4.3 现实提醒：VLA 上机载非常吃紧

- 主流开源 VLA（如 7B 级）FP16 需 ~14 GB 显存，**Orin NX 16G / Orin 100 TOPS 基本跑不动**，
  即使 INT4 量化也只勉强，且延迟不满足闭环。
- **务实路线（强烈建议）**：
  1. **不要指望端到端大 VLA 直接输出关节力矩**。
  2. 用 **ACT（Action Chunking Transformer）/ 扩散策略** 这类**小模型模仿学习**做操作技能，
     参数量 10–100 M，Orin 上可实时（10–30 Hz）→ 这是任务 2/3/5 的现实主力。
  3. VLA 只用**高层**：把"按清单顺序抓取"这类**语言条件任务解析**成子目标序列（低频、非实时），
     子目标再由 ACT/规划器执行。
  4. **大规模训练在仿真 + 离线工作站**做，机上只做推理。训练算力可以外置（离线不受 2.1.5 限制）。
- **显存预算**：Orin NX 16G 上，感知 + 策略同时驻留，实际可用显存 ~12 GB。
  要提前做**模型瘦身**（蒸馏、量化、剪枝）。

### 4.4 算力冗余方案

| 方案 | 说明 | 成本 |
|---|---|---|
| 单 SoC | 现状（Orin 系列） | 0 |
| **SoC + 加装 Jetson Thor / Orin AGX 模组** | 感知/策略专用，与运动控制物理隔离 | +2–5 万 |
| 双机热备（整机冗余） | 一台主机 + 一台备机 | 平台价 ×2 → 一般不划算 |

> 建议：**主机单台 + 关键模组备件**（备用关节模组 ×2、备用电池 ×4、备用算力模组 ×1、备用足垫 ×2 套）。
> 原因：1.2 续航 ≥25 min 且 5.7 有"解体/起火/漏液无效"，**现场换关节比修关节现实**。

## 五、电气与安全方案

| 项 | 要求（条款） | 做法 |
|---|---|---|
| 急停 | 机载物理急停 + **无线远程急停**（1.3.2 / 6） | 硬件急停按钮 + 独立无线急停接收机（**与主控解耦**，直接切动力） |
| 失控处理 | **关节缓慢卸力，禁止剧烈甩动**（6.2.1） | 急停后走"主动阻尼下蹲"序列，而不是硬断电 |
| 力矩保护 | 关节力矩限幅、冲击保护，防堵转烧毁（1.3.1） | 电流阈值 + 温度阈值 + 堵转检测三级 |
| 电池安全 | 动力锂电，过压/欠压/过流/过热保护；**禁止改装非标电池**（1.3.3 / 6） | 只用原厂电池；BMS 数据接入监控；不做私改 |
| 温度 | 环境 5–40℃（4.3） | 低温续航预案；电机关节温度监控与降功率策略 |
| EMC | 不得干扰他机/定位/通信（1.3.3） | 屏蔽走线、共模扼流、避免赛事定位频段；进场前 EMI 自测 |
| 结构安全 | 无尖锐外露棱角，外壳缓冲（6） | 3D 打印缓冲包覆件（TPU），所有关节外缘圆角 |
| 关节限位 | 高速关节设限位装置（6） | 硬件机械限位 + 软件限位双重 |
| 围挡 | 测试/比赛区安全隔离围挡（6） | 自备可折叠围挡（含防撞软包） |

### 5.1 动力链路示意

```
原厂电池（快拆）─→ 主接触器 ─┬─→ 关节驱动总线（CAN-FD / EtherCAT）
                              ├─→ 算力模组 DC-DC（隔离）
                              └─→ 传感器 DC-DC（隔离，低噪）
                
急停链路（独立）：
   物理急停按钮 ─┐
   无线急停接收 ─┴─→ 硬件与门 ─→ 主接触器断开 + 触发"主动阻尼下蹲"
```

> **要点：急停必须绕过主控软件。** 若急停依赖主控（已死机）→ 无效。
> 同时"断开动力"和"缓慢卸力"要分开设计：断开是安全兜底，卸力是 6.2.1 的合规动作，两者都要。

## 六、"30 秒就位"的工程化

附则一.3：**队伍需在 30 秒内完成机器人就位。**

对 35–45 kg 的人形机器人，这是实打实的操作。方案：

1. **定制运输台车**：带滚轮 + 可调高度平台，机器人在台车上处于"待启动姿态"，推到起点后直接放脚。
2. **预置姿态**：机器人默认进入"支撑站立/跪姿"低重心状态，便于抬放。
3. **一键上电脚本**：开机 → 自检 → 站起 → 待命，全流程自动化，目标 ≤ 15 s，留 15 s 余量。
4. **人员分工固定**：2 人抬运 + 1 人操作地面站 + 1 人报时。
5. **反复演练**：就位动作练到闭眼能完成，至少 20 次。
