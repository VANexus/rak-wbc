# 技术攻关 ④ 全身负重控制（任务 4：伤员转运）

> **5.2 任务 4**："抱起假人并顺利通过指定赛道"（完全通过 12 / 有条件通过 7）
> 这是**风险最高的任务**：既受"假人质量"这一未知量制约，也是唯一要求**负重动态平衡**的任务。
>
> ⚠️ 前提仍是拿到假人质量（见 `05-待确认问题清单.md` P0-1）。本文给出**拿到之后怎么做**，
> 以及在**拿不到/超载重**时的降级设计。

---

## 一、先算清楚：负重对质心的影响有多大

**这一步必须先算，因为它直接决定任务是否物理可行。**

机器人总质量 $m_r$，假人质量 $m_l$，假人质心相对机器人质心前移 $d$。
合体质心前移量：

$$\Delta = \frac{m_l \cdot d}{m_r + m_l}$$

### 1.1 数值表（假设 $m_r = 35$ kg，抱在躯干前方 $d = 0.30$ m）

| 假人质量 $m_l$ | 合体质心前移 $\Delta$ | 评价 |
|---|---|---|
| 3 kg | **2.4 cm** | ✅ 可承受，常规补偿即可 |
| 5 kg | **3.8 cm** | ✅ 可行，需明显后倾 |
| 8 kg | **5.6 cm** | ⚠️ 临界，需大幅后倾 + 短步 |
| 12 kg | **7.7 cm** | ⚠️ 很可能超出 ZMP 裕量 |
| 20 kg | **11.0 cm** | ❌ **单足支撑下基本不可能** |

> **判据**：人形单足支撑多边形前后向裕量约 **±(脚长/2) ≈ ±0.10–0.13 m**，
> 且行走时质心还要做动态摆动。**前移超过约 5 cm 就开始显著压缩稳定裕量；超过 8 cm 基本不可行。**
>
> → **这解释了为什么"假人质量"是第一号风险**：
> **若假人 >8–10 kg，现有 170 cm 以下平台物理上做不到"抱起行走"。**

### 1.2 还要叠加两个恶化因素

1. **双臂环抱 = 失去摆臂平衡**。正常人行走靠摆臂抵消角动量；抱东西时这个自由被占用
   → 必须用**躯干扭转 + 步态调整**代偿。
2. **假人是软体、会晃**。行走时假人相对躯干有摆动 → 质心偏移量**随时间振荡**，
   峰值可能比静态值大 30–50%。

> 合起来：**动态峰值前移 ≈ 静态 $\Delta$ × 1.3–1.5**。
> 回到上表：3 kg → 3.1–3.6 cm（安全）；8 kg → 7.3–8.4 cm（危险）。

## 二、方案：定姿规划 + 负载在线估计 + 质心级 MPC + WBC

### 2.1 架构

```
        抱姿选择（offline）          负载在线估计（online, 200–500 Hz）
        ┌────────────────┐          ┌──────────────────────────────┐
        │ 双臂环抱腋下/腰背│          │ 由臂关节力矩 + IMU + 足底力   │
        │ 假人尽量贴近躯干 │          │ → 估计 m_l 与质心偏移 d       │
        │ 减小 d 与力矩   │          │ （对格挡/缓和有用）           │
        └───────┬────────┘          └──────────────┬───────────────┘
                │                                  │
                └──────────────┬───────────────────┘
                               ↓ 负载参数
        ┌──────────────────────────────────────────────────────────┐
        │ Centroidal MPC（把负载视为附加质量，重算质心动力学）      │
        │  约束：ZMP ∈ 支撑多边形（裕量收紧） / 摩擦锥 / 步长上限    │
        └───────────────────────────┬──────────────────────────────┘
                                    ↓ 期望质心轨迹 + 接触力
        ┌──────────────────────────────────────────────────────────┐
        │ WBC（QP）：质心跟踪 / 躯干后倾姿态 / 摆动足轨迹 /         │
        │            接触力分配 / 关节限位 / 力矩限幅                │
        └───────────────────────────┬──────────────────────────────┘
                                    ↓
                          关节伺服（力矩模式）
```

参考路线：
- **Adaptive Whole-Body MPC with Optimal Posture Planning**（arXiv:2610.12972）——
  **Centroidal MPC + WBC** 的组合架构，且包含**最优姿态规划**，正是"负重时该摆什么姿势"的问题。
- **Gravity-Compensated MPC and WBC**（ASME J. Mechanisms and Robotics 18(3): 031007）——
  重力补偿的 MPC+WBC，实测"稳定行走、平衡控制、躯干跟踪、平滑过渡"。
- **HUGWBC**（RSS 2025，开源）—— 通用全身控制器，支持细粒度指令（步频/步高/站姿），
  可直接作为**基线**并在其上加负载补偿。
- **RPL**（arXiv:2602.03002）—— 已验证"**负重时仍鲁棒**"的感知式运动策略。

### 2.2 负载在线估计

不要假设"假人质量已知且恒定"。要做**在线估计**：

| 观测量 | 用途 |
|---|---|
| 双臂关节力矩 − 空载预测力矩 | 估计负载重力矩 → 推 $m_l$ 与作用点 |
| 躯干 IMU 姿态/角速度 | 估计负载引起的额外力矩 |
| 足底力分布 | 校核合质心位置 |

**用途**：① 自适应调整后倾角；② 检测假人滑落（负载工况突变）；③ 供上层判断是否需要降级。

### 2.3 定姿规划（"该摆什么姿势"）

| 策略 | 作用 |
|---|---|
| **躯干后倾** | 把合质心拉回支撑区。后倾角随估计的 $m_l$ 自适应 |
| **假人贴近躯干** | 减小 $d$ → 直接减小 $\Delta$（**收益最大的一招**） |
| **缩短步长** | 减小动态摆动与单足支撑时间 |
| **加大横步宽** | 增大侧向稳定裕量 |
| **提高双足支撑占比** | 减少单足支撑（最脆弱）的时间 |
| **降速** | 0.3–0.5 m/s（5.5 时间分仍可接受） |
| **头部/上肢微调** | 用可用的残余自由度做角动量补偿 |

> ⭐ **"假人贴近躯干"是性价比最高的一招**：$d$ 从 0.30 m 减到 0.20 m，
> 5 kg 假人的前移量从 3.8 cm 降到 2.5 cm。
> **抱姿设计（把假人贴身、双手托住臀背而不是悬空拎着）比任何控制器调参都有效。**

## 三、动作序列与失败恢复

### 3.1 执行序列

```
1. 接近 + 定位      ← 假人 6D 位姿估计
2. 下蹲（深蹲）      ← ⚠️ 峰值膝扭矩工况，见 §3.2
3. 双臂环抱 + 夹紧    ← 贴身！检测夹紧力
4. 起身（负重起身）   ← ⚠️ 第二个峰值扭矩工况
5. 负载在线估计 → 定姿补偿
6. 负重行走（降速/短步/宽站姿）
7. 通过指定赛道 → 放下
   ── 任一步失败 ──→ 见 §3.3
```

### 3.2 两个峰值扭矩工况（必须先验证）

| 工况 | 风险 | 验证方法 |
|---|---|---|
| **下蹲抱起** | 深蹲 + 双臂前伸 → 膝/髋/踝扭矩峰值 | 台架/吊架实测关节峰值扭矩，与平台裕量对比 |
| **负重起身** | 从深蹲站起并携带 $m_l$ | 同上 |

> ⚠️ **若平台膝扭矩裕量不足（G1 基础版膝 90 N·m，EDU 120 N·m），
> 负重起身会触发 1.3.1 的"力矩保护"→ 降额 → 站不起来 → 任务失败。**
> **必须在选型前做这个力矩核算**（这也是"假人质量"要早确认的原因之二）。

**规避技巧**：不要让机器人从"最低深蹲"起步 ——
**先把假人搬到半高（如矮凳/垫块）上，或采用"单膝跪姿"起抱**，可显著降低起身扭矩需求
（前提：赛规未禁止改变假人初始高度 → 属待确认项）。

### 3.3 失败恢复（对应 5.2 的 7 分档）

> 5.2 任务 4 有条件通过 = "行进中假人**掉落但自主抱起**继续完成"

→ **必须实现"掉落 → 重新抱起"闭环**：

```
负载估计突变 / 臂部力骤降  →  判定掉落
   → 立即停止行走（原地稳定）
   → 判断假人位置（视觉 + 深度）
   → 后退避让 → 下蹲 → 重新环抱 → 起身 → 继续
```

**这是把 12 分档事故兜到 7 分档的保险，投入产出比极高。必须做。**

## 四、降级方案：拖拽式转运（当假人超载重时）

若假人质量超出平台臂载（很可能会），**"抱起"物理上不可行**。此时：

| 方案 | 说明 | 得分预期 |
|---|---|---|
| **拖拽（drag）** | 双臂抓假人上肢/衣领，**假人贴地拖行**通过赛道 | 可能拿到"完成赛道通行"→ 争取 **7 分** |
| 半拖半抬 | 一臂托头部，假人部分离地 | 居中 |
| 分阶段搬运 | 抱一段、放下、再抱（若规则允许） | 若允许，可能仍算"抱起" |

**拖拽方案的工程要点**

1. **大幅降低负载力矩**：拖行时垂直方向载荷主要由地面承担 → 臂只需提供水平拉力 +
   少量抬升 → 有效负载需求可能降到 1–2 kg 级 → **可行性质变**。
2. **摩擦是主变量**：假人与地面的摩擦系数决定所需拉力。**务必在赛前确认假人材质与地面材质**
   （问题清单里的环境复核项）。
3. **质心影响反而更小**：拉力作用点在下方 → 对合质心的前移贡献远小于"抱在胸前"。
4. **风险**：可能被判定"未抱起"→ 0 分。**必须先向组委会确认"拖行是否被认可"**（P0-1 的分问题）。
5. **实现**：本质上仍是"双臂施加拉力 + 全身平衡"，可复用 §2 的 MPC/WBC 架构，
   只是把负载模型从"附加质量"改为"**附加阻力/拉力约束**"。

> **建议：把"抱起"和"拖拽"做成两个可切换的技能**，现场按组委会裁决与实测可行性择一，
> 甚至在比赛中动态降级（抱起失败 → 切拖拽）。这符合 `技术攻关 ③` 里"多技能 + 降级"的总思路。

## 五、验证方案

| 阶段 | 内容 | 通过判据 |
|---|---|---|
| V1 | 台架/吊架：负重静力平衡（无行走） | 原地站立 30 s 不晃 |
| V2 | 吊架保护：负重原地踏步 | 连续 60 s 不摔 |
| V3 | 负重直线行走 5 m | 3 次成功，无假人掉落 |
| V4 | 负重行走 + 转向（弯道） | 通过 4.2-6 弯道 |
| V5 | 负重下蹲-起身循环 ×5 | 不触发力矩保护/温度告警 |
| V6 | **掉落 → 自主重抱** | 人为制造掉落 10 次，成功重抱 ≥8 次 |
| V7 | 满负载 + 全赛道路线 | 通过指定赛道 |
| V8 | 拖拽方案（若采用） | 通过指定赛道 |

**真机测试必须用吊架保护**（负重失稳摔倒的破坏性远大于空载摔倒）。

## 六、风险与对策

| 风险 | 对策 |
|---|---|
| **假人质量未知/超载重** | 见 P0-1；预备拖拽降级方案；选型时按最大可用载重取 |
| 负重起身触发力矩保护 | 核算峰值扭矩；用单膝跪姿/半高起始降低需求 |
| 假人滑动/掉落 | 夹紧力检测 + §3.3 自主重抱闭环 |
| 动态晃动放大失稳 | 建模为柔性负载 + 仿真域随机化；**贴身抱姿**减小力臂 |
| 失去摆臂平衡 | 躯干扭转代偿 + 加大横步宽 + 提高双足支撑占比 |
| 拖拽被判无效 | 赛前书面确认；保留"抱起"路径 |
| 负重摔倒破坏性大 | 吊架保护测试；保守的速度与步长上限 |

## 七、一句话总结

> **任务 4 的成败，80% 取决于"假人质量"这个已确定的物理量，20% 取决于控制。**
> 拿到质量后：
> - 若 ≤5 kg → 走"贴身环抱 + 质心级 MPC(WBC) + 后倾自适应"，目标 12 分；
> - 若 5–10 kg → 同方案但大幅降速、短步，目标 7 分，并做重抱闭环；
> - 若 >10 kg → **直接做拖拽方案**，目标 7 分。
