# 交付材料 ③ 跌倒自恢复能力测试视频 · 拍摄脚本

> 依据：技术文件 7.3 —— "跌倒自恢复能力测试视频"
> 目标：一份能让裁判**在 2 分钟内确认"该机器人具备可靠的自主跌倒恢复能力"**的视频。
> 关键：**必须是连续无剪辑镜头**（否则被质疑剪辑造假），**必须显示计时**，**必须覆盖多种路面与姿态**。

---

## 一、硬性要求（先记住这 6 条）

| # | 要求 | 原因 |
|---|---|---|
| 1 | **每个恢复过程必须一镜到底**，不剪辑、不加速 | 剪辑会直接作废可信度 |
| 2 | **画面内必须有计时器**（马表/秒表/大屏幕计时） | 5.3 明文要求 **3 秒内**自恢复，裁判要看时间 |
| 3 | **必须覆盖 3 种姿态**：趴（俯卧）、仰（仰卧）、侧翻 | 不同姿态恢复难度不同 |
| 4 | **必须覆盖多种路面**：平地、斜坡、碎石 | 3.1 步态集 + 4.2 障碍环境 |
| 5 | **全程无任何人工接触**（人不得进入画面触碰机器人） | 5.3"需外力得 0 分" |
| 6 | 画面内可见**完整的机器人**，不能只拍局部 | 证明是自主动作而非剪辑 |

---

## 二、视频规格

| 项目 | 建议 |
|---|---|
| 时长 | **2–4 分钟**（不超过 5 分钟，裁判不会看完） |
| 分辨率 | 1920×1080 或更高，30/60 fps |
| 机位 | 主机位：侧前方 3–5 m，中景（全身入画 + 计时器入画）<br>副机位（可选）：正前方，用于展示姿态变化 |
| 音频 | 保留现场音（可听到关节声与地面声，增强可信度）；**不要配乐** |
| 字幕 | 每个片段标注：编号 / 姿态 / 路面 / 恢复耗时 |
| 计时器 | 画面内实体秒表或叠加时间码，**两者都有最好** |

## 三、镜头清单（按顺序拍摄）

### 片头（10 s）

```
字幕：
  参赛项目：人形机器人越野赛（全自主组）
  队伍：<队伍名称>   机器人：<型号>
  材料：跌倒自恢复能力测试视频
  说明：以下每段均为连续无剪辑镜头，画面内含计时器，全程无人工接触
```

**必须拍到**：机器人完整外观 + 画面中的实体计时器同框（建立"计时可信"）。

### 片段 1｜平地 · 俯卧（趴姿）—— 3 次

| 项 | 内容 |
|---|---|
| 路面 | 平整地面 |
| 初始姿态 | 俯卧（面朝下） |
| 测试次数 | 3 次连续 |
| 画面要求 | 全身入画；计时器同框；无人员靠近 |
| 字幕 | `片段1 平地/俯卧/第n次  恢复耗时: ___ s` |
| 记录 | 每次实测耗时，最差一次作为申报值 |

### 片段 2｜平地 · 仰卧 —— 3 次

> 仰卧（面朝上）通常比俯卧更难，因为需要先翻身。**这是最容易被质疑的一项，必须拍足。**

### 片段 3｜平地 · 侧翻 —— 3 次

### 片段 4｜斜坡 · 俯卧 / 仰卧 —— 各 2 次

| 项 | 内容 |
|---|---|
| 路面 | 斜坡，坡度 `<实测值，如 12°>`（4.2 要求 10–15°） |
| 要求 | **上坡向与下坡向各拍一次**（下坡恢复更难） |
| 字幕 | `片段4 斜坡 <__°> / <姿态> / <朝坡上|朝坡下>` |

### 片段 5｜碎石 · 俯卧 —— 3 次

| 项 | 内容 |
|---|---|
| 路面 | 碎石（粒径 `<实测，如 10–40 mm>`，与 4.2-1 一致） |
| 要求 | 展示在**非平整、接触不确定**的路面上的恢复能力 |

### 片段 6｜（加分）台阶/颠簸路面 · 俯卧 —— 各 1–2 次

> 非必须，但能显著提升材料说服力，且覆盖 4.2-3 / 4.2-5 的环境。

## 四、拍摄执行清单

**器材**

- [ ] 主机位相机/手机（三脚架固定，避免抖动）
- [ ] 副机位（可选）
- [ ] **实体秒表或大屏计时器**（必须入画）
- [ ] 场记板/白板（写片段编号，便于后期打字幕）
- [ ] 照明（确保姿态细节可见；**但注意 4.3 说明比赛无强制补光，不要用灯光掩盖真实光照条件**）

**场地**

- [ ] 平整地面
- [ ] 斜坡（`<实测坡度>`，与 4.2-2 的 10–15° 一致）
- [ ] 碎石路面（粒径与 4.2-1 的 10–40 mm 一致）
- [ ] 安全围挡（第三章 6 要求，视频里出现围挡也是合规的体现）

**拍摄纪律**

- [ ] 所有人员退到安全距离外，**不得入画**
- [ ] 每次跌倒后**不喊话、不指示、不靠近**，让机器人自主完成
- [ ] 若某次失败（>3 s 或未站起），**保留在视频里并如实标注**（诚实反而增加可信度；
      只展示成功片段会被质疑选择性剪辑）
- [ ] 全程记录每次耗时（表格），用于片尾汇总
- [ ] 同一天内完成全部片段（光照/环境一致，减少剪辑嫌疑）

## 五、后期处理（最小化）

**允许**
- 片头/片尾字幕
- 每个片段叠加**标注字幕**（姿态/路面/耗时）
- 片段之间**硬切**（不叠加转场特效，避免"跳接"嫌疑）
- 音量归一化

**禁止**
- ❌ 对恢复过程做任何剪辑（含抽帧、跳切、拼接）
- ❌ 变速（加速/减速）
- ❌ 裁剪掉机器人任一部分或计时器
- ❌ 配乐掩盖现场音
- ❌ 在失败片段上删掉失败部分

**输出**

- [ ] 文件名：`<队伍名>_跌倒自恢复测试_v<版本>_<日期>.mp4`
- [ ] 提交格式：MP4 (H.264)，1080p
- [ ] 同时保留**原始未编辑素材**备查（若被质疑可提供）

## 七、与比赛评分的对映关系（为什么这样拍）

| 视频要素 | 对应评分条款 | 分值 |
|---|---|---|
| 每段含计时器、耗时 ≤3 s | 5.3 稳定性"摔倒后 3 秒内自恢复" | 影响 6 分 |
| 全程无人工接触 | 5.3"需外力得 0 分" | 避免 6 分归零 |
| 覆盖多种姿态与路面 | 第三章 3"步态集含跌倒恢复步态" | 条款合规 |
| 连续无剪辑 | 材料可信度（7.1 赛前会**现场复测**此项） | 影响能否通过检查 |
| 同时是"传感器功能验证"的旁证 | 7.1 赛前技术检查 4 项 | 影响参赛资格 |

> **提醒**：7.1 赛前技术检查会**现场演示跌倒自恢复**。
> 视频拍得好但现场做不到，等于白拍，还可能被怀疑材料不实。
> **视频里的成绩必须是真机的稳定成绩**，不是最好一次的成绩。
