## 0. 摘要

本机器人采用 **分层解耦的感知–规划–控制架构**：低频智能（感知、任务编排、操作策略）与
高频实时控制（状态估计、全身控制）在**物理隔离的计算域**中运行，通过无锁通信交换数据。
**全部推理在机载完成**，符合 2.1.5"禁止场外实时传回图像、下发运动指令"的要求。
出发后**全程无人工输入**，符合 5.4"全自主"等级定义。

## 1. 总体架构

```
┌───────────────────────────────────────────────────────────────────┐
│ 【感知】Perception            10–30 Hz        GPU                 │
│   深度/双目/LiDAR → 地形高度图；检测分割 → 目标位姿；打卡点识别     │
├───────────────────────────────────────────────────────────────────┤
│ 【规划】Planning              1–50 Hz         CPU+GPU             │
│   任务编排(FSM) → 全局路径 → 局部避障(边界硬约束) → 落脚点规划      │
│              → 操作规划(有序任务 → 抓取/拔线/投放序列)             │
├───────────────────────────────────────────────────────────────────┤
│ 【控制】Control               200–1000 Hz     实时CPU/MCU          │
│   状态估计 → MPC(质心+ZMP) → WBC(QP全身控制) → 关节伺服(力矩)       │
└───────────────────────────────────────────────────────────────────┘
  横切：安全与故障处理 │ 裁判接口(状态码/轨迹上报) │ 全程日志留存
```

### 1.1 计算域隔离（关键设计）

| 计算域 | 内容 | 频率 | 隔离手段 |
|---|---|---|---|
| **实时域** | 关节伺服、WBC、MPC、状态估计 | 200–1000 Hz | PREEMPT_RT + CPU 隔离核，独占，**永不阻塞** |
| **感知域** | 高度图、检测分割、位姿估计 | 10–30 Hz | GPU (TensorRT)，独立进程 |
| **决策域** | 任务编排、局部/全局规划、操作规划 | 1–50 Hz | 普通核，无实时约束 |
| **操作域** | 操作策略推理（ACT/Diffusion Policy） | 10–30 Hz | GPU，仅在操作相位激活 |

> **设计理由**：人形机器人对控制频率敏感（<200 Hz 易失稳），而视觉/策略推理存在抖动。
> 两者必须物理隔离，用**共享内存无锁队列**通信，实时域永不等待非实时域。
> **当感知或策略超时，实时域自动回退到模型基保守控制，而非等待或停机。**

### 1.2 技术栈

| 层 | 选型 |
|---|---|
| 中间件 | ROS 2 `<Humble/Iron>`（实时域走自研 RT 线程） |
| 仿真/训练 | Isaac Lab（RL + 域随机化）；LeRobot/ACT（操作模仿学习） |
| 推理部署 | TensorRT / ONNX Runtime |
| SLAM/定位 | `<FAST-LIO2（LiDAR-惯导） / OpenVINS>` + GNSS/IMU EKF |

## 2. 感知子系统（对应 2.1）

### 2.1 模块构成

| 模块 | 输入 | 输出 | 频率 |
|---|---|---|---|
| 躯干状态估计 | IMU + 关节编码器 + 足底力 | 躯干位姿/速度 | 500 Hz |
| 接触与打滑检测 | 足底力 + 关节电流 + 足端速度残差 | 接触概率 / 打滑标志 | 500 Hz |
| **地形高度估计** | 深度图 + LiDAR 点云 | **2.5D 高度图** | 20–30 Hz |
| 可通行性分析 | 高度图 | 坡度 / 台阶高 / 粗糙度 / 危险区掩码 | 20 Hz |
| 全局定位 | GNSS + IMU (+ LiDAR 里程计) | 赛道坐标系位姿 | 20–50 Hz |
| 打卡点识别 | 相机 | 打卡点 ID + 相对位姿 | 10 Hz |
| 操作目标感知 | 操作相机 + 腕部相机 | 引线/物品/药箱/假人/目标区 的类别 + 6D 位姿 | 10–30 Hz |

### 2.2 对照 2.1 能力要求

| 2.1 要求 | 对应实现 |
|---|---|
| 识别碎石、凹凸地面、台阶、斜坡，**输出地形高度估计** | 高度图模块（§2.1），对负向不连续（台阶边缘/浅坑）显式标记为跌落风险，不做插值平滑 |
| 检测赛道障碍物、**边界**，不冲出赛道 | 可通行性分析输出危险区掩码；边界在规划层作为**硬约束**（代价 = ∞） |
| 沿赛道行进、绕过静态障碍、支持打卡点识别 | 全局中心线跟踪 + 局部代价图 A*/DWA + 打卡点视觉识别 |
| 跌倒、打滑、传感器失效时**输出故障状态** | 故障检测模块 → 状态码 `FALLEN`/`FAULT` + 分级降级（§5） |

### 2.3 关键设计说明

- **高度图用于控制而非仅用于显示**：坡度/台阶高直接进入 L3 的通行代价与落脚点约束。
- **负向不连续显式建模**：台阶段与浅坑会表现为高度图"洞"，被标为不可通行，避免踏空。
- **定位双模冗余**：GNSS 可用时用 GNSS/IMU EKF；遮挡时切换到 LiDAR-惯导里程计（FAST-LIO2）。
- **打滑检测不依赖视觉**：以足底力 + 关节电流 + 运动学残差为主，视觉失效时仍可用（对应 3.2 抗扰动）。

## 3. 规划子系统

### 3.1 任务编排（L5，1–5 Hz）

```
INIT → SELF_CHECK → (裁判发令) → TASK_QUEUE
          ↓
    EXEC_TASK[i]
      ├─ 完成 → NEXT_TASK → (全部完成) → FINISH
      ├─ 单项超时 T_budget[i] → SKIP_AND_CONTINUE   ← 跳过，绝非放弃
      ├─ 跌倒 → FALL_RECOVERY → (≤3s 站起) → 回到 EXEC_TASK[i]
      ├─ 打滑/障碍微调 → LOCAL_REPLAN → 回到 EXEC_TASK[i]
      ├─ 出界 → RETURN_TO_NEAREST_MARKER → 回到 EXEC_TASK[i]
      ├─ 低电量 → 前往补给站换电 → 回到 EXEC_TASK[i]
      └─ 故障 → DEGRADE_MODE（降速/换保守策略）→ 继续
```

> **架构原则：状态机中不存在"放弃/等待人工/停机"状态。**
> 依据 5.7 第 1 条——"出发后 15 分钟未完赛**且已停止尝试**"才判无效。
> 只要保持运动或重试，就永远不触发无效成绩；且 5.5 注规定"已通过任务仍计任务分"。

**时间预算**：每项任务设硬上限 `T_budget[i]`，以 10 分钟完赛（时间分满分）为目标反推。

| 任务 | 硬上限 | 超出动作 |
|---|---|---|
| 密林穿越 | `<120 s>` | 降速继续推进（必经路线，不可跳过） |
| 雷区侦察 | `<150 s>` | 跳过剩余引线 |
| 收纳急救物品 | `<180 s>` | 跳过剩余物品 |
| 伤员转运 | `<150 s>` | 降级为拖拽，否则跳过 |
| 丛林投物 | `<90 s>` | 保证投掷动作成立 |

### 3.2 全局与局部规划

| 层 | 方法 | 约束 |
|---|---|---|
| 全局 | 赛道中心线跟踪 + 打卡点序列 | 沿指定路线（5.2 任务 1"按指定路线到达终点"） |
| 局部 | 代价图 + A*/DWA 重规划 | **边界 = 硬约束（∞）**；静态障碍绕行；动态目标避让 |
| 落脚点 | 候选点采样 + 代价最小化（或学习型打分） | 落点坡度 / 台阶高 / 距边界裕量 / 足端可达性 |

**代价函数**

```
cost = w1·坡度 + w2·粗糙度 + w3·台阶高 + w4·静态障碍 + w5·动态目标 + w6·偏离中心线
约束（硬）：越出赛道边界 → ∞        不可通行区 → ∞
```

> **为什么边界必须是硬约束而非高代价**：4.4 规定"任意部位持续越出边界"即判冲出赛道
> （5.6 另列为每次 −2 分）。软惩罚下最优化器仍可能贴边行进；赛道最窄仅 1.2 m 而机器人身高 >1.2 m，
> 横向余量极小，必须硬性保证不越界。

### 3.3 出界恢复行为（对应 4.4）

被判定出界后，机器人**自主**执行：

```
BOUNDARY_VIOLATION → 沿已走过的路径反向运动 → 回到最近标记点 → 恢复任务
```

> 4.4 明确"需退回最近标记点，并执行罚时"。该行为由机器人自主完成，
> 若原地不动会被判"已停止尝试"，触发 5.7 无效成绩。故此行为是**必需功能**。

### 3.4 操作规划（L4）

| 任务 | 规划方式 |
|---|---|
| 雷区侦察 | 解析"颜色顺序"→ 序列队列 → 逐根：识别→对准→夹紧→沿引线方向匀速后拉 |
| 收纳急救物品 | 解析"清单顺序"→ 抓取队列 → 每件：识别分类→抓取→移到药箱上方→位姿调整→放入 |
| 伤员转运 | 抱姿规划（贴近躯干以减小质心偏移）→ 全身协调行走 → 掉落则停止-蹲下-重抱 |
| 丛林投物 | 抓取 → 目标区定位 → 抛投策略（末端速度 + 释放时机） |

**容错设计（对应 5.2 的"有条件通过"档）**

- 顺序错误 ⇒ 仅降为"有条件通过"（12→7），**不是 0 分** → 策略上先保证"动作完成"，再优化"顺序正确"。
- 物品掉落 / 假人掉落 ⇒ 实现**自主拾取 / 自主重抱**，把 12 分档的事故兜到 7 分档。

**语言条件任务解析**：由低频（0.2–1 Hz）的视觉语言模型把清单/图卡解析为子目标序列，
子目标再交给实时性可满足的操作策略（ACT / Diffusion Policy，10–30 Hz）执行。
**大模型只做"理解"，不做实时闭环控制。**

## 4. 控制子系统（对应第三章 3）

### 4.1 控制栈

```
步态调度（6 类步态 + 恢复步态）
   ↓ 接触序列 + 速度指令
MPC（质心轨迹 + ZMP 约束，预测时域 0.5–1.0 s，步长自适应）
   ↓ 期望质心轨迹 + 期望接触力
WBC（QP 全身控制）
   变量：全身关节加速度/力矩
   任务：质心跟踪 / 躯干姿态 / 摆动足轨迹 / 接触力分配
   约束：ZMP ∈ 支撑多边形 / 摩擦锥 / 关节限位 / 力矩限幅
   ↓ 关节力矩
关节伺服（力矩模式）：力矩限幅 / 冲击保护 / 温度降额 / 堵转检测
```

**双策略并行**：学习型 RL 步态策略（复杂地形性能上限）＋ 模型基 MPC/WBC（安全网）。
感知或策略异常时**自动切换**到模型基保守策略，**不等待人工介入**。

### 4.2 六类步态（对应 3.1）

平地快走 / 平地慢走 / 碎石崎岖 / 跨障 / 上下坡 / 台阶 / **跌倒恢复**（共 7 类，含恢复态）。

### 4.3 跌倒恢复（对应 3.1、5.3）

**独立有限状态机**（不依赖视觉，仅用 IMU + 关节位置 + 足底力）：

```
IDLE → DETECT（姿态阈值 + 触地）→ 姿态分类（趴/仰/侧翻）
     → PLAN（选择恢复动作序列）→ EXECUTE（100 ms 检查进度）
     → RETRY_ALT（最多 N 次）→ STABILIZE（站立稳定 1 s）→ IDLE
```

- **时延目标 ≤3 s（5.3 硬性要求），设计值 `<≤2 s>`**
- 恢复过程限制关节外摆幅度，符合 6.2"禁止剧烈甩动"
- 在平底 / 斜坡 / 碎石路面分别验证

### 4.4 抗扰动与自主应对（对应 3.2、5.4）

| 扰动 | 检测 | 自主响应 |
|---|---|---|
| 足底打滑 | 足端速度残差 + 力突变 | 缩短支撑相、重算落脚点 |
| 碎石移位 | 接触力消失 | 原地试探、更换落脚点 |
| 障碍位置微调 | 地图与感知不一致 | 触发局部重规划绕行 |
| 路面凹陷/浅坑 | 高度图负向突变 | 急停该步、后退、换路 |

### 4.5 状态码输出（对应 3.3）

`NORMAL_WALK` / `OBSTACLE_CROSS` / `FALLEN` / `FAULT` / `LOW_BATTERY`
通过无线链路实时上报裁判系统，并在本机屏幕同步显示；延迟 <200 ms；断连自动补传。
**仅上行状态与位置，无图像上传、无运动指令下行（符合 2.1.5）。**

## 5. 安全与故障处理（对应第三章 6）

### 5.1 故障分级

| 级别 | 判据 | 响应 |
|---|---|---|
| 轻度 | 单传感器失效 | 降级融合，限速继续任务，上报故障码 |
| 中度 | 打滑频发 / 关节温高 / 电流异常 | 降速、换步态、缩短任务步数 |
| 重度 | 电池告警 / 关节异常 / 姿态失控 | 原地自主停机并上报 |
| 紧急 | 冒烟 / 异响 / 失控 | 硬件急停（物理 + 无线，裁判亦可触发） |

### 5.2 急停动作（符合 6.2.1）

```
急停触发 → 冻结运动指令 → 主动阻尼下蹲（0–300 ms）→ 低姿支撑（≤1.5 s）
        → 力矩降至支撑所需 → 若仍异常则断开动力
禁止：直接断电导致机身重摔；恢复/急停过程中的剧烈关节甩动
```

### 5.3 看门狗

各层独立看门狗；实时域超时 → 自动回退模型基安全控制；
与地面站通信中断**不影响比赛**（地面站非必需，符合 1.1/2.1.5）。
