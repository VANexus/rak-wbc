# ADR 0001: 模型基 WBC 优先于 RL 主线

- 状态：Accepted
- 日期：2026-10-21

## 背景

原 `技术攻关/01`、`02` 的主线是 Isaac Lab 训练 RL 策略再 sim2real。
本项目实际约束是：只有机载算力，没有 GPU 训练集群；且比赛临近。

RL 路线的优势是复杂地形适应性和速度上限，但需要：

- 大量并行仿真环境；
- 域随机化与 sim2real 标定；
- 策略训练/蒸馏/部署链路；
- 真机分阶段验证时间。

这些在赛前都不具备。

## 决策

运行时主线采用**模型基控制**：

```text
质心 MPC（50–100 Hz）
  → WBC 分层 QP（500–1000 Hz）
    → 关节力矩/位置
```

- 起身/跌倒轨迹用 Crocoddyl 离线生成，WBC 跟踪；
- 复杂地形先用官方 SDK 步态 + 姿态补偿 + 落脚点规则；
- RL 仅作为赛后可选，不作为赛前依赖。

## 后果

### 正面

- 可解释、可调试、可验证；每个失败都能定位到估计/规划/控制层。
- 全 CPU 可跑，Orin NX 足够。
- 不需要 sim2real 标定周期。
- 显式约束 ZMP/摩擦锥/力矩限位，符合比赛“保持 ZMP 稳定”的表述。

### 负面

- 复杂地形性能上限低于 RL；需要更保守的速度/步长。
- 依赖模型精度；必须做在线参数辨识。
- 起身/跌倒动作比 RL 慢，需要准静态设计。

## 备选方案

1. **纯 RL + sim2real**：性能上限高，但赛前不可行。
2. **官方步态 + 仅做上层**：最稳，但拿不到全身姿态控制能力。
3. **模型基 + RL 混合**：长期最优，但当前先把模型基跑通。
