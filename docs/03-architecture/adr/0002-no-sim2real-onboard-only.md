# ADR 0002: 不做 sim2real，只有机载算力

- 状态：Accepted
- 日期：2026-10-21

## 背景

比赛要求全机载、禁止场外算力；团队没有 GPU 训练集群。
Isaac Lab 4096 环境的训练路线需要多卡 GPU 和数天到数周的训练时间。

## 决策

1. **不做策略训练与 sim2real 迁移**。
2. 仍然使用**离线仿真**做模型验证与轨迹生成（MuJoCo/Pinocchio），
   但这不被视为 sim2real，也不产生需要迁移的学习策略。
3. 用以下手段替代域随机化：
   - 在线参数辨识（质量/质心/摩擦/延迟/足底力零点）；
   - 保守裕量（力矩 80%、摩擦锥 0.6μ、步长/步高留 20%）；
   - 阻抗/导纳控制吸收地形误差；
   - 扰动观测器估计外力/负载；
   - 准静态动作库作为安全网。

## 后果

### 正面

- 赛前可交付；不需要训练集群。
- 所有行为可复现、可解释、可现场调参。
- 模型基控制器在 CPU 上实时性可控。

### 负面

- 复杂地形速度/鲁棒性上限较低。
- 起身/跌倒动作更慢，需要精心设计关键帧与接触时序。
- 模型不准时性能下降明显；参数辨识是前置条件。

## 备选方案

1. **租 GPU 训练**：时间/成本不允许。
2. **用官方预训练策略**：平台/版本不确定，且无法针对赛道调优。
3. **纯规则控制**：最稳但能力上限低，作为降级层保留。
