## 6. 维护约定

- 新增技术文档放在 `技术攻关/`，并在 `技术攻关/README.md` 与本索引登记。
- 新增架构决策写 ADR，编号递增，不修改已接受的 ADR（改用新 ADR 取代）。
- 官方文件更新时，旧版移入 `reference/archive/`，不要覆盖。
- 文档中的链接使用相对路径，保证在 GitHub/本地都能打开。
