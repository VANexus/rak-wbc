# hardware

平台 SDK、接线、标定记录。**这里是唯一允许记录 SDK 细节的地方**；
业务包不得直接依赖 SDK。

## 待确认清单（SDK 全开放假设下）

- [ ] 控制模式：位置 / 速度 / 力矩；流式还是指令式
- [ ] 最高控制频率；端到端延迟
- [ ] 关节反馈：位置/速度/力矩/电流/温度；频率
- [ ] IMU：频率、量程、噪声、时间戳
- [ ] 足底力：通道数、量程、安装位置、零点漂移
- [ ] 电池 BMS：电压/电流/温度/SOC
- [ ] 急停：软件触发、硬件回路、卸力斜坡
- [ ] 通信：TCP/UDP/CAN/EtherCAT；是否需要实时线程
- [ ] 是否允许旁路官方控制器；保修/安全边界
- [ ] 官方 URDF/惯性参数/关节限位/力矩上限
